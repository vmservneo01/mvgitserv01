СЛЕЖБЫ KUBERNETES
pods - служба для контейнера в kubernetes
deployments - взаимодействие с контейнерами,запуск одного например или нейсколько контейнеров
services - объект через который пользователи могут подключаться к контейнеру
kubectl get pod -A - посмотреть какие контейнеры уже запущены в kubernetes
kubectl create deployment --image=ghcr.io/vmservneo01/flatris:latest vmservkub01(указываем удаленный репозиторий и имя vmservkub01)  
- (нужно создать объект типа deployment(как раз запихнуть образ с Github Packeges в kubernetes)
kubectl get deploy - посмотреть какие деплои существуют
kubectl describe deploy vmservkub01- посмотреть инфо о деплое(vmservkub01 - это его имя)
kubectl scale deployment --replicas=3 vmservkub01 - запустить несколько контейнеров в kubernetes
kubectl expose deployment vmservkub01 --port=3000 --target-port=3000 --type LoadBalancer 
- типа запуск сервиса к которому пользователи смогут подключиться (тобишь к контейнеру)
(--type LoadBalancer нужен для того чтобы пользователи смогли подключаться,иначе если его не будет то это получится все локально)
kubectl get service - просмотр сервисов
